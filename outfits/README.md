# 换装 · 给画衣服的人

她 10/13 夜里画了四套换装（飞行帽、贝雷帽、睡帽、毛领风雪帽；手绘原稿留在家里，没跟着搬出来），画在一个比他高一截的身板上。10/15 凌晨把原稿缩下来贴上去试穿，整件缩、拆开缩都对不上，她定了重画。这一层就是给重画搭的架子：一套衣服不再是贴在静图上的一张皮，而是引擎里的两层——帽子画在礼帽那个位置、衣服画在马甲那个位置——这样四十个动作里的每一帧，帽子该落后就落后、该歪就歪、睡着了就躺到地上，全部白来。

**她原稿每套两张：`<名字>-b.png` 是正面，`<名字>-a.png` 是背面。** 正面一律照 b 画；a 只给侧身帧（`ctx.side`）露出来的后背那半截用（后脑、背上的缝和带子、睡帽尾巴往后垂的走向）。一套就是一件，不再分 a / b 两件——10/15 早上她点破之前，第一版把 a 当正面穿上了身、b 又另挂一件 `*-b.cjs`，复审都没看出来。

不穿衣服的时候什么都不变：`node export.cjs` 出来的 40 态和改之前逐字节相同。

## 一套衣服是什么

一个文件 `outfits/<名字>.cjs`（名字小写字母、数字、`-`、`_`），导出一个对象。照着 `_template.cjs` 抄一份最快。

**许可**：四套衣服（`aviator`、`beret`、`nightcap`、`winter-fur`）是她的设计，文件头写的是 CC BY-NC-SA 4.0：可以拿去改、去分享，署名带上、不商用、改出来的也照样敞开。
`_template.cjs` 走 MIT，抄去画你自己的衣服不受这些限制——抄完把开头四行换成你的名字和你选的许可。

| 键 | 必填 | 是什么 |
|---|---|---|
| `name` / `label` | 否 | 名字记进 `meta.outfit`；label 给人看 |
| `palette` | 否 | 这套衣服自己的颜色 `{ beretRed: '#6c1a26' }`。名字照老规矩小驼峰英文，值必须是 `#rrggbb`。只给这一套用，不进 `manifest.json` 那 19 色；**和老色重名直接报错**（重名等于给他整个人换了色） |
| `hat(ctx, x, y, scale, angle)` | 否 | 画帽子。不写就戴礼帽 |
| `costume(ctx, { body, bottom, vestHeight, p })` | 否 | 画衣服。不写就穿马甲 |
| `hideBag` | 否 | `true` 时连皮包带肩带一起摘。不写就照背——他是信差，包不离身 |
| `hideWatch` | 否 | `true` 时摘掉马甲上的表链和怀表（外头套了大衣，表链浮在大衣上很怪） |

调色板里老的 19 色（`ink`、`skin`、`hatRim`、`gold`……）照样能用。

### 帽子的 ctx

引擎在原来画礼帽的两处（头上那次、躺在地上那次）都改成先问衣服有没有帽子。帽子拿到的是**礼帽那个框里的坐标**：

| | |
|---|---|
| `ctx.rect(lx, ly, w, h, color = 'ink', tag)` | 在框里画一块。引擎替你乘 `scale`、套礼帽同一个 transform、画进 `hat` 层 |
| `ctx.pattern(rows, lx, ly, color = 'ink', unit = 5)` | `['0110','1111']` 这种点阵，`'1'` 画一格 |
| `ctx.x / y / scale / angle` | 这一帧框的左上角、大小（头上 1、地上 0.5）、角度。一般用不着 |
| `ctx.transform` | `{ cx, cy, a }`：绕框底边中点 `(70, 40)` 转 `a` 度 |
| `ctx.aside` | 帽子躺在地上（睡着，或伸懒腰第 6 帧刚坐起来还没扣回去） |
| `ctx.sleep` / `ctx.side` | 睡姿 / 侧身 |
| `ctx.body` / `ctx.p` | 这一帧身子的框、姿势（拷贝，改了也没用） |
| `ctx.onHead` | `{ x, y, angle }`：这一帧「戴在头上那一顶」的框，帽子躺在地上的帧也给。睡着也不摘的帽子（睡帽）用它把自己画回头上，不用再抄引擎那条式子 |

`tag` 会自动加上 `outfit-` 前缀写进 `meta.parts`，不会和手、脚、眼睛的 tag 撞。

### 衣服的 ctx

| | |
|---|---|
| `ctx.rect(x, y, w, h, color = 'ink', tag)` | **画布绝对坐标**，套身子的 transform（身子 lean 时一起歪），画进 `costume` 层 |
| `ctx.pattern(rows, x, y, color = 'ink', unit = 5)` | 同上，点阵 |
| `ctx.waistcoat()` | 原样画一件马甲（要在大衣里头留马甲边，就先调它再往上盖） |
| `ctx.body` / `ctx.bottom` / `ctx.vestHeight` / `ctx.p` | 和第二个参数同一份 |
| `ctx.eyes` | 这一帧每只眼睛那一格 `{ x, y, w: 10, h: 20 }`（闭眼、半眼也按睁眼那一格给），兜帽留脸窗用 |
| `ctx.side` / `ctx.sleep` / `ctx.transform` | 侧身 / 睡姿 / 身子的 transform |

兜帽、围脖这种贴脸、会盖到眼睛能走到的那一块的东西画在衣服里（`costume` 层），`eyes` 层在它上面，眼睛会自己盖上来；**不要**画在帽子里，`hat` 层在眼睛上面。
挂在脸两边、碰不到眼睛的（护耳、睡帽尾巴）反过来最好画在帽子里，守着下面「y 40 以下只在 x < 20 或 x ≥ 120」那条：跟帽子一起落后、横挪、被抬起来，一整圈不断——
风雪帽第一稿护耳在衣服层、毛圈在帽子层，帽子一被挪、被抬，兜帽就撕成两截。

**套在头上的帽子，被抬起来时只让顶上那一截走**（1015 第一批复审）：风雪帽原来整顶兜帽连毛圈、护耳一起跟着 `hatLift` 抬（扶帽致意 12、震惊愣住 15、大笑颠飞 15），
毛圈的底边离开头顶，脸窗最上面露出一条背景色的横带，像戴了副眼罩。兜帽是套着脸的：手掀得起圆顶，掀不走那一圈毛和两片护耳。
现在 `hat()` 里拿 `ctx.p.tool` 的抬（和引擎同一条式子：`hatLift` 与 `|hatTilt| × 1.3` 取大、取整）把毛圈和护耳的 y 加回去，只有圆顶三行跟着抬，
缝开在圆顶和毛圈之间——和礼帽抬起来时檐下那道缝是同一个意思。以后再画兜帽、头巾这种「套着」的帽子照这个办；
新动作的 `verify` 要量「帽子悬起来」的话，别只看头顶上那 10 行（震惊愣住改成了从帽子框顶往下找连着 10 行空的）。

**压扁的时候衣服上的浅色细节会挤成一张嘴**（同一轮）：睡衣站直 25 高，奶白的领子、两个领尖、扣子隔得开；压 10 以上只剩 15 高，
领子横一道、领尖两个、下摆一道浅蓝挤在眼睛正下方，大笑的「∩」眼一配就是咧嘴笑的两排白牙。睡衣现在不足 20 高时不画领子。
画衣服的人跑 `--preview` 时顺手看一眼压得最扁的那几帧（蓄力高跳落地、大笑笑瘫），脸底下那一截别冒出横着的一道浅色。

## 三条铁律

1. **眼睛那一行必须露着。** 帽子底边不能过框里的 `y = 40`。
2. **衣服宽度跟身子走。** 用 `body.x`、`body.w` 画，别比他窄。
3. **帽子画在礼帽那个框里。** 底边就是 `y = 40`，不高不低——高了帽子离头、头顶露一道缝。

`--preview` 会替你查这三条，查出来照样出图，退出码记 1。

## 锚点数字

画布 300 × 300，脚底基线 y 273，10px 主格、5px 细部，纵向原点偏 3px（画布上的行从 3、8、13……起）。下面「框」指帽子的局部坐标，「画布」指绝对坐标。

**待机首帧（就是 `static/clawd-idle.png`）**

| 部件 | 画布坐标 |
|---|---|
| 身子 body | x 90–210，y 208–263（120 × 55），`bottom` 263 |
| 礼帽框 | 左上角 (80, 168)，x 80–220，y 168–208；帽顶那一行 x 125–175，檐 y 201–208 整宽 140 |
| 眼睛 | x 115–125 和 175–185，y 213–233（10 × 20） |
| 马甲 | x 90–210，y 243–263（`vestHeight` 20） |
| 皮包 | x 189–224，y 238–268；肩带从左腰 (93, 245) 斜到包上 |
| 手 / 脚 | 手 x 70–90 和 210–230、y 223–243；脚 x 105 / 135 / 165 / 195、y 263–273 |

**帽子（框里的坐标，scale 1）**

- 框 140 × 40，左上角 (0, 0)，框底边 `y = 40` 正好贴着头顶 `body.y`。他的身子在框里是 x 10–130（被抱起来那几帧整顶横挪 ±10，引擎已经算进 `x` 了）。
- **眼睛最高会顶到框里 y 40**，横向在 x 25–115（正面两只眼，含眼珠左右看 ±5 和帽子横挪 ±10）；侧身那只眼在 x 100–115。这是把 40 态 1851 帧逐帧量过的。所以 y 40 以下只许画在 x < 20 或 x ≥ 120（再留 5 给转角），护耳、睡帽尾巴往两边垂可以，往中间垂不行。
- **往上画，最好别过 y 0（礼帽顶那一行）**。好几样东西是贴着礼帽顶排的：打伞的伞面最底一行在框里 x −40 到 65、y −8 到 −3；伸懒腰 14–22 两只手举在 x 25–45 和 95–115、最低到 y 2（顶行宽过 45–95 就按在帽顶上）；晕乎乎三颗星绕着帽子转，转到后面那颗画在帽子底下；报错的「!」那个点在 x 66–76、y −11 到 −3。
  真要冒出去（她画的护目镜、贝雷帽的顶粒、风雪帽的圆顶），冒在 x 45–95 中间那一段撞得最少；撞没撞，跑 `node check-art.cjs --outfit <名字>`（见下面「整套查一遍」）。
  这一条第一版写的是「往上画不限」，四套里有两套因此高出礼帽、跟伞和手撞上，复审才查出来。
- 这一帧的框已经带上了：`hatLag`（跳起来帽子落后）、`hatDrop`（沉一下，最多 5）、`hatTilt` / lean（转角 −8° 到 +4.2°）、`hatLift`（抬帽最多 12）、`hatShift`（横挪 ±10）。帽子一行不用管这些。
- 礼帽的轮廓是帽顶一行和两头檐尖用 `hatRim` 提亮，深底（`#0d1430`）上才看得出形状。深色帽子照这个办法。

**眼睛那一行**

- 醒着：每只眼那一格顶在 `body.y + 5 + gazeY`（gazeY −5 到 +5），10 × 20；闭眼是贴在格子底部的 10 × 5，半眼是下半截 10 × 10。正面两只在 `body.x + 25`、`body.x + 85`，侧身一只在 `body.x + 90`，都再加 gazeX（±5）。
- 所以眼睛最低到 `body.y + 30`。**衣服顶边别高过 `body.y + 30`**，不然眼睛像长在布上；模板用的是 `Math.max(body.y + 30, bottom - 30)`。

**身子**

- 醒着 `body.w` 永远 120；`body.x` 80–102（走动），`body.y` 130–220（跳），`body.h` 43–65（压扁拉长）；`bottom = body.y + body.h`，185–263。
- 衣服按 `bottom` 往上量最稳（马甲就是这么画的），按 `body.y` 往下量会跟着压扁拉长。两头都想跟就像模板那样取 max。
- 肩带只在 `costume` 层有像素的地方露出来（引擎每帧按衣服剪一次）。正面它从 `vestTop + 2` 斜到 `vestTop + 11` 再接到包上（`vestTop = bottom − vestHeight`）；摘了马甲又没盖住这一带，肩带就跟着没了。

**侧身**（走路、慢悠悠走、小跑、冲刺、向前跃、陪钓、看星星、画画、鼓脸里的侧身帧）

- 朝右，身子左边 20 列是 `skinSide` 阴影（背），眼睛只有一只在右边，皮包和肩带挪到左边（背后）。
- 帽子照常调，`ctx.side` 为真。对称的帽子什么都不用改；不对称的（睡帽尾巴、护耳）自己看 `ctx.side` 决定往哪边垂——尾巴垂向背后（左）才像在走。
- 侧身那只眼只在框里 x 100–115，所以侧身时 y 40 以下 x < 95 都碰不到眼睛：风雪帽侧面耳朵那一侧的整片毛就画在这一段。
- 衣服想和身子一样有背面阴影，就把左边 20 列压暗（模板里有一行）。

**睡姿**（睡着，伸懒腰 0–5）

- 身子 `{ x: 95, y: 221, w: 110, h: 42 }`，`bottom` 263，`vestHeight` 15；眼睛是闭眼，在 `body.y + 11`，x `body.x + 25`、`body.x + 75`。
- 帽子不在头上：框的左上角 (216, 253)、`scale` 0.5、`angle` 0，躺在他右边地上，框底贴着基线 273。`ctx.aside` 为真。伸懒腰第 6 帧人坐起来了、帽子还在地上，也是这样（那一帧 `ctx.sleep` 为假）。
- 半大时 5px 的细部会变成 2.5px，光栅化后有的 2 行有的 3 行。要在地上也认得出的东西用 10px 画，或者看 `ctx.aside` 干脆省掉（比如绒球）。

**镜像**：指路朝西那种 `mirror: true` 的版本，衣服跟着整张翻，什么都不用写。

## 整套查一遍

```sh
node check-art.cjs --outfit beret
```

四十个动作 1851 帧每一帧都穿上这件，跑老伦敦那一整套解剖检查（眼睛被盖、头顶缝、伞面碰没碰帽子、晕星露全没有、伸懒腰的手按没按在帽顶上、首末帧和睡着/待机全等……），结果打在终端里、按结果给退出码，**不写** `anatomy-check.json`（那份是不穿衣服的验收记录）。摘了包的衣服（`hideBag`）指路那两条不再要求包在。
10/15 第二轮（正面照 b、侧身后背照 a，四套各合成一件）的结果：飞行帽、贝雷帽、睡帽全过（飞行帽的护目镜压回框里 y 0，伞面不再碰镜片）；风雪帽还是 `dizzyThreeStarsTwoEyes`、`umbrellaDryBody`、`stretchingHandoff` 三条——都因为圆顶照她的比例比礼帽高 20，要不要压矮等她定。四套的 `coveredEyePixels`、`hatGapPixels` 都是 0。
搬出来住那天（10/16）四套又整套查了一遍：`npm run check:outfits` 四套都是 0 条问题、0 条提醒，风雪帽上面那三条也过了。

## 总表：她画的和他穿上的对着看

```sh
node tools/outfit-sheet.cjs                              # 存到 outfits/preview/sheet-outfits.png（不进 git）
node tools/outfit-sheet.cjs --originals <原稿目录>        # 最左边多一格原稿，文件照 <衣服名>-b.png（正面）、<衣服名>-a.png（背面）起名
```

一行一件（飞行帽、贝雷帽、睡帽、风雪帽），列是 衣服 | 他原样待机 | 穿上待机（放大 2 倍）| 走路 | 睡着 | 挥手 | 被抱起来。深蓝底 #0d1430、每格裁到他所在的下半区（裁剪框按这几帧实际画出来的外框现量，衣服改大了不会切掉）。
家里那张表最左边是她的原稿：正面 b 原样大小在前，对右边几格正面的他；背面 a 缩一半在旁边，对「走路」那一格侧身露出来的后背。原稿没跟着搬出来，所以默认不画那一格；`docs/img/outfits.png` 就是不带原稿的这一张，README 里用的也是它。

## 还没有的

- 手和脚还是皮肤色，衣服包不到（没有袖子、裤腿）。要的话下一步给衣服开一个 `hands` 的口子。
- 换装只出预览，`node export.cjs` 整包导出不认 `--outfit`；正式出一套换装的 40 态得另加导出路径（check-art 已经认 `--outfit` 了）。
